# Code by Ade

I’m a designer who codes, which means my software projects usually start with curiosity and end with an obsession over how the thing feels in a real person’s hands. Some of these projects were products, some were experiments, and some were data-heavy side quests that turned into much bigger undertakings than I expected.

I’ve built iPhone apps, interactive tools, data projects, websites, and strange little digital objects that sit somewhere between utility and storytelling. What ties them together is that I like making software that is memorable, human, and a little unexpected.

Github: [@adrian3](https://github.com/adrian3)
